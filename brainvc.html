Frames are encoded in your browser (WebCodecs) at 1920×1080 with a keyframe every second, faster than real time. Data frames/s: at most half of the video frame rate. Works in Chrome, Edge, Opera, Firefox 130+ and Safari 16.4+; without H.264 support a WebM is created.
Tip: low bitrate music works best, e.g. ffmpeg -i in.mp3 -c:a libopus -b:a 16k out.webm or an MP3 at 32–64 kbit/s. Pick a frame rate that divides your screen refresh rate (10, 12, 15, 20, 30 for 60 Hz). In fullscreen the code fills the entire screen, so a shared fullscreen tab needs no corner adjustment on the receiving side.

BrAiNVC v4.0 · optical data link

Encoder and scanner for an optical data link: a file becomes a stream of pixel frames (header, CRC16, Reed-Solomon error correction), which can be shown on a screen, put into a video, and read back from a screen, a video file or a camera. This web edition does the live work and can also create video files; brainvc.au3 / brainvc.exe is the file tool for encoding and decoding with ffmpeg. Both use the same frame format.

Settings

Everything you set on this page is remembered in this browser. Reset brings back the defaults, which are the same as in brainvc.au3: grid 160×90, K = 8, M = 2, 10 data frames/s, 5 s beacon, 60 fps video, 2 file repeats (plus: 10 s pre-buffer, Live play, Exact file reading).
