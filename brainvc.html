Lossy codecs lose high tones: Opus below 64 kbit/s keeps roughly 3 kHz, MP3 needs about 96 kbit/s for 4800 baud. Frame size, K and M come from the Format panel above; smaller frames lose less when a codec damages one. "Verify" decodes the finished MP3/WebM again, so you know at once whether the settings survive.

A-Link audio file (WAV, MP3 or WebM/Opus)
Select an audio file created by A-Link.
How it works: a fixed 1200 baud preamble (sync word plus all settings) leads into the data tones, so the receiver finds the start and the settings on its own, even after the codec delays the signal. Frames use the same CRC16 and Reed-Solomon recovery as the optical link. WebM/Opus is recorded in real time by the browser (as long as the playing time); WAV and MP3 are created faster than real time. MP3 encoding loads the lamejs library from a CDN once.

BrAiNVC · optical + experimental acoustic (A-Link) data link

Encoder and scanner for an optical data link: a file becomes a stream of pixel frames (header, CRC16, Reed-Solomon error correction), which can be shown on a screen, put into a video, and read back from a screen, a video file or a camera. Note: v5 is not backward compatible – videos made with v4 or older versions cannot be read, and v5 videos cannot be read by them.
