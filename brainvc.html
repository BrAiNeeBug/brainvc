Format (sender and receiver must use the same values)
Same frame format as brainvc.au3 (header, CRC16, Reed-Solomon over groups of K+M frames).
 Mode:
By default the whole video frame is read. Drag the corners only if the code sits in a smaller area (TL = top-left of the code).
What the scanner sees
Tips: with a camera keep the code big and the phone steady, use a low data rate (about 5–8 frames/s) and avoid reflections. Live play works for MP3 and WebM/Opus streams; other files are saved and, if they are audio, played after the transfer completes.
Choose a file (MP3 or WebM/Opus for live listening) and press Start. A beacon (logo, then 3-2-1) runs first, so you have time to start the receiver.
Tip: low bitrate music works best, e.g. ffmpeg -i in.mp3 -c:a libopus -b:a 16k out.webm or an MP3 at 32–64 kbit/s. Pick a frame rate that divides your screen refresh rate (10, 12, 15, 20, 30 for 60 Hz). In fullscreen the code fills the entire screen, so a shared fullscreen tab needs no corner adjustment on the receiving side.
